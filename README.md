# Thanaa Khaled - Personal Portfolio

## Project Overview

A personal portfolio website created to represent my professional identity and digital presence.

The website presents my educational background, skills, training, projects, and contact information.

## Project Objective

The objective of this project is to build a simple and professional personal portfolio while applying the methodologies learned during the training.

The project follows a structured workflow from business requirements to product requirements, implementation, testing, and debugging.

## Project Structure

- `BRD.md` - Business Requirements Document
- `PRD.md` - Product Requirements Document
- `design.md` - Website Design Document
- `TESTING.md` - Testing and Debugging Documentation
- `index.html` - Website structure
- `style.css` - Website styling

## Technologies

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- Markdown

## Main Website Sections

- About Me
- Skills
- Education
- Training & Certifications
- Projects
- Contact

## Methodology

The project was developed following these main steps:

1. Define business requirements through the BRD.
2. Convert business requirements into an engineering plan through the PRD.
3. Break the PRD into an Epic, Stories, and Tasks.
4. Implement the website.
5. Use GitHub to track project changes through commits.
6. Test the website and document the testing and debugging process.
7. Publish the website using GitHub Pages.
